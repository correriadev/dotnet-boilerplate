# Project Digest

## LAST UPDATED
2026-10-07

## ARCHITECTURE SUMMARY
- Baseline: Hexagonal + Clean dependency direction; Vertical Slices in Application; .NET 8/C# 12.
- Layers: Domain, Application/ports, Infrastructure/adapters, YARP Gateway, HTTP/worker hosts, Delivery & Migration hosts.
- Landing Zone: VNet 10.0.0.0/16 com 3 subnets (/24) isoladas por NSGs; snet-data sem IPs públicos e 100% fechada para a internet com acesso exclusivo via snet-apps e Private Endpoints.
- Borda & Gateway: YARP API Gateway (.NET 8) na porta 8080 para tráfego local; validação e propagação W3C (traceparent 55 chars); repasse intacto de Authorization Bearer; mitigação de path traversal e sanitização de logs.
- Transacional: Azure SQL 2022 (Dapper + DbUp em [pix]); réplica síncrona BC_Gen5_2 com readScale: Enabled para consultas contábeis (0.00m estrito sem saldos sintéticos); Redis 7 fail-closed com fallback IMemoryCache bounded.
- Broker & Outbox: Service Bus FIFO sessions (SessionId = ContaId); OutboxRelay com TOP (@batchSize) e UPDLOCK, READPAST; Outbank ACL com timeout de 2s e Polly v8.
- CI/CD & Delivery: 6 artefatos em containers imutáveis, assinatura Cosign keyless, manifestos OCI no ACR via ORAS, deploy automático em Dev e gates manuais em Hml/Prod.
- Observabilidade: W3C Trace Context ponta a ponta; sanitização estrita de PII; Dynatrace SRG fail-closed em Hml; Dynatrace Davis AI com circuit breaker em bake de 10 min em Prod.
- Schema Evolution: Pix.Migrator em ACA Job para DbUp, cálculo dinâmico de range e validação pré-rollback.
