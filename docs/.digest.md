# Project Digest

## LAST UPDATED
2026-10-06

## ARCHITECTURE SUMMARY
- Baseline: Hexagonal + Clean dependency direction; Vertical Slices in Application; .NET 8/C# 12.
- Layers: Domain, Application/ports, Infrastructure/adapters, HTTP/worker hosts, Delivery & Migration hosts.
- TO BE: Azure SQL Server 2022 (Dapper + DbUp no schema `[pix]`) é a autoridade transacional; réplica síncrona com `ApplicationIntent=ReadOnly` com integridade contábil estrita (0.00m sem saldos sintéticos); Redis 7 para admissão fail-closed; fallback resiliente para IMemoryCache bounded (SizeLimit) e Circuit Breaker.
- Financial commands: Azure Service Bus com FIFO sessions (`SessionId = ContaId`), filas parametrizáveis (`pix-cashout-requested`, `pix-cashout-completed`), EndToEndId único BACEN (32 chars) e reconciliação.
- Local ACID transactions: Dapper + SqlTransaction; OutboxRelay via T-SQL com `TOP (@batchSize)` e `WITH (UPDLOCK, READPAST)`; chamadas externas (SPI BACEN) via Outbank ACL com timeout de 2s e Polly v8.
- Autenticação e Perímetro: Validação OIDC perimetral (`IOidcAuthValidator`) com retorno HTTP 401 Unauthorized nas APIs CashOut e Billing; suporte a `Auth:SimulatedMode=true` para CI/testes.
- CI/CD & Delivery: 6 artefatos em containers imutáveis, assinatura Cosign keyless, manifestos OCI no ACR via ORAS, deploy automático exclusivo em Dev e gates manuais em Hml e Prod.
- Schema Evolution: Pix.Migrator executável rodando em ACA Job para migrações DbUp, cálculo dinâmico de range e validação pré-rollback.

## TESTING SUMMARY

- Commands: `dotnet test azure-cloud-estudos.sln --logger "trx;LogFileName=test_results.trx"`.
- Cobertura e Validação: 158 testes (75 Unit, 82 Integration, 1 Architecture) com 100% de aprovação (0 falhas).
- Quality Gate: Pirâmide contínua com parsing OpenCover multi-projeto (Domain 90%, Application 85%, Infrastructure 80%, Global 85%).
- Suítes Especializadas: autenticação perimetral OIDC, réplica síncrona, RefCountedLock, resiliência LRU bounded, topologia Service Bus FIFO, timeouts DDL Pix.Migrator e gates de promoção CI/CD (TS-01 a TS-25, TS-TL-01 a 05).
